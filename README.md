## 📖 Aperçu du contenu

### Partie 1 — Fondamentaux des moteurs de recherche
Histoire et évolution · Fonctionnement technique (Crawl, Index, Rank) · PageRank · IA dans les moteurs (RankBrain, BERT, MUM) · Parts de marché

### Partie 2 — Indexation (pilier technique)
Processus d'indexation · Robots.txt et Sitemap XML · Balises Meta Robots et Canonical · Budget de crawl

### Partie 3 — SEO On-Page
Recherche de mots-clés · Intention de recherche · Balises HTML (title, meta, headings) · Images et multimédia · Maillage interne

### Partie 4 — SEO Technique Avancé
Core Web Vitals · Performance web (CDN, HTTP/2, caching) · Mobile-First Indexing · Données structurées (Schema.org) · JavaScript SEO · SEO International · Entity SEO

### Partie 5 — SEO Off-Page
Netlinking et backlinks · Stratégies de link building · E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness) · Content Marketing SEO

### Partie 6 — SEO Spécialisé
SEO Local · Migration SEO · E-commerce SEO · CMS (WordPress, Shopify, Webflow) · Vidéo et Voice Search · A/B Testing

### Partie 7 — Mesure et Analyse
Google Search Console · Google Analytics 4 · KPIs et Reporting

### Partie 8 — Stratégie et Tendances
Audit SEO complet · Plan d'action stratégique · SEO et Intelligence Artificielle (SGE, ChatGPT, contenu IA)

## 🚀 Comment utiliser

### Consulter le cours
```bash
# Ouvrir le PDF du cours
ouvrir Guide_Complet_Formation_SEO_Indexation_Referencement.pdf

# Ou compiler depuis la source LaTeX
pdflatex rapport_seo.tex
pdflatex rapport_seo.tex
```

### Générer la présentation
```bash
python3 create_pptx_30.py
# → Génère Presentation_Formation_SEO_30_Diapositives.pptx
```

### Consulter les exercices
```bash
# Version PDF combinée
ouvrir TD_Combine.pdf   # Tous les TD (38 pages)
ouvrir TP_Combine.pdf   # Tous les TP (35 pages)

# Ou version markdown pour modification
code TD/TD01_*.md
code TP/TP01_*.md
```
